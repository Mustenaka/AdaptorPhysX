# 路线图

目标：Unity 开源体素柔体插件，支持动态切割与半切割，面向虚拟手术场景。

## 已确定的决策（2026-10-20）

| 编号 | 决策 |
|---|---|
| 1 | 仅支持 Unity。实现为 Burst + Jobs，GPU 后端为 Compute Shader。其他引擎与 C++ 版本不在计划内。 |
| 2 | 确定性要求为同一机器、同一构建、相同输入下结果可复现，由一个测试覆盖。不要求跨后端逐位一致。 |
| 3 | 布料、绳索、多引擎冻结，代码保留在 `archive/*` tag。 |
| 4 | 单一 git 仓库，仓库根目录即 Unity 工程。 |
| 5 | 每个里程碑的验收以下列标准场景的截图或录屏为准，由人工判断效果；性能与确定性其次。 |

## 里程碑

| 里程碑 | 内容 | 状态 |
|---|---|---|
| M1 | 体素化、co-rotational XPBD（替换 Neo-Hookean）、碰撞与摩擦、钉住、抓取、渲染嵌入、休眠 | 已完成。人工验收（2026-10-28）：基本形状（组织块、皮瓣、肝叶、组织垫与交互演示中的物体）上的柔体与交互作为第一个版本通过 |
| M2 | 扫掠面断棱、virtual node 副本、切面生成与裁剪、切面着色器、皮肤沿切平面拆分 | 已完成。人工验收（2026-10-28）：同 M1，范围为基本形状 |
| M3 | 块间接触（已完成）；不同物体之间的接触（已完成）；拓扑与渲染拓扑局部重建；刀路在体素内弯曲时的切口精度 | 进行中 |
| M4 | Compute Shader 求解后端；渲染顶点在 GPU 上直接写入 Mesh 顶点缓冲 | 未开始 |
| M5 | 组织分层：皮肤层刚度与切向预应力、切面按深度分层着色（已完成）；脂肪/肌肉不同材料；超阈值撕裂；编辑器 blueprint 资产缓存体素化结果（已完成） | 进行中 |
| M6 | 真实网格：高面数、不规则、不闭合、带细小结构的网格（扫描版兔子、龙、Fertility、器官分割网格）上达到基本形状的效果。条目：BUG-10、PERF-10（开放网格）、PERF-6（高面数表面更新与切割帧重建）、PERF-7（初始化）、PERF-5 与 PERF-2（高分辨率）、MED-7（细小结构）、BUG-13（不规则网格落地后轻节点抖动）；BUG-3 / PERF-9 在高分辨率下评估。验证依赖 ENG-3 的基准基线；人工验收用标准场景 S12 | 进行中 |

M3 以后的顺序可按人工验收时发现的问题调整。2026-10-28 起 M6 优先：基本形状通过人工验收后，下一阶段的目标为真实网格。

## 工作约定

- 文档只保留 `README.md`、`docs/DESIGN.md`、`docs/ROADMAP.md`、`docs/TODO.md`，以及代理工作约定 `CLAUDE.md`。
  不再为单个任务写计划与交接文档。
  `docs/TODO.md` 是待办与现状的对照表，条目带编号，完成或发现新问题时更新。
- 每个改动附带 EditMode 测试（拓扑、守恒、无 NaN 等可自动判断的性质），影响效果的改动附带标准场景截图。
- 提交信息使用 Conventional Commits。代理完成修改并验证后直接提交，不推送（见 `CLAUDE.md`）。
