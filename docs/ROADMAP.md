# 路线图

目标：Unity 开源体素柔体插件，支持动态切割与半切割，面向虚拟手术场景。

## 已确定的决策（2026-10-20）

| 编号 | 决策 |
|---|---|
| 1 | 仅支持 Unity。实现为 Burst + Jobs，GPU 后端为 Compute Shader。其他引擎与 C++ 版本不在计划内。 |
| 2 | 确定性要求为同一机器、同一构建、相同输入下结果可复现，由一个测试覆盖。不要求跨后端逐位一致。 |
| 3 | 布料、绳索、多引擎冻结，代码保留在 `archive/*` tag。 |
| 4 | 单一 git 仓库，仓库根目录即 Unity 工程。 |
| 5 | 每个里程碑的验收以下列标准场景的截图或录屏为准，由人工判断效果；性能与确定性其次。 |

## 标准场景

`AdaptorPhysX/Capture Standard Scenarios` 按脚本执行以下场景并输出截图（`docs/images/` 为当前结果）。

| 编号 | 场景 | 验收内容 | 当前结果 |
|---|---|---|---|
| S1 | 组织块全切 | 切穿后两块分离，可被镊子拉开，切面完整 | 2 块 |
| S2 | 预应力皮瓣半切 | 切口停在组织内部，切口在张力下张开 | 1 块，切口张开 |
| S3 | 十字切与再次切割 | 交叉切得到四块；已分离的块可以继续切 | 5 块 |
| S4 | 镊子牵拉切口边缘 | 抓取不跨越切口，牵拉时组织形变连续 | 切口张开，露出切面 |
| S5 | 肝叶楔形切除 | V 形两刀加两端横切，楔形块可被取出 | 楔形块分离并被提起 |
| S6 | 实体组织上的小切口 | 带皮肤层的组织块上切一道短而浅的切口：皮肤张力使切口张开，切口下方仍为实体；牵开后露出真皮、脂肪分层 | 1 块，切口张开，底部闭合 |

## 里程碑

| 里程碑 | 内容 | 状态 |
|---|---|---|
| M1 | 体素化、co-rotational XPBD（替换 Neo-Hookean）、碰撞与摩擦、钉住、抓取、渲染嵌入、休眠 | 已完成，待人工验收 |
| M2 | 扫掠面断棱、virtual node 副本、切面生成与裁剪、切面着色器、皮肤沿切平面拆分 | 已完成，待人工验收 |
| M3 | 块间接触（已完成）；不同物体之间的接触；拓扑与渲染拓扑局部重建；刀路在体素内弯曲时的切口精度 | 进行中 |
| M4 | Compute Shader 求解后端；渲染顶点在 GPU 上直接写入 Mesh 顶点缓冲 | 未开始 |
| M5 | 组织分层：皮肤层刚度与切向预应力、切面按深度分层着色（已完成）；脂肪/肌肉不同材料；超阈值撕裂；编辑器 blueprint 资产缓存体素化结果 | 进行中 |

M3 以后的顺序可按人工验收时发现的问题调整。

## 工作约定

- 文档只保留 `README.md`、`docs/DESIGN.md`、`docs/ROADMAP.md`。不再为单个任务写计划与交接文档。
- 每个改动附带 EditMode 测试（拓扑、守恒、无 NaN 等可自动判断的性质），影响效果的改动附带标准场景截图。
- 提交信息使用 Conventional Commits。
